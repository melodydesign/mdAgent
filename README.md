# mdAgent

Сервис для автоматической кастомизации и доработки сайтов на платформе Tilda по текстовым командам.

mdAgent управляет браузером Chromium через Playwright, ориентируется в административной панели Tilda, вносит визуальные и структурные изменения, инспектирует реальную верстку страниц и проводит замкнутую валидацию (Closed-Loop) опубликованного результата.

---

## Ключевые возможности

- **Автономное выполнение задач в админке Tilda**: поиск проектов и страниц, навигация, добавление блоков из каталога, изменение настроек шторки и правка контента.
- **Двухвкладочный рабочий контур**:
  - Вкладка 1: панель управления Tilda (редактирование, вставка кастомного CSS/JS в блок T123, публикация).
  - Вкладка 2: боевой сайт (исследование живого DOM, чтение вычисленных стилей, выявление реальных селекторов).
- **Closed-Loop верификация**: после публикации система открывает сайт на второй вкладке, анализирует DOM, проверяет скрытие нативных селектов, рендеринг кнопок вариантов, примененные стили и консоль JavaScript на наличие ошибок. В случае расхождений агент автоматически корректирует код.
- **Интеллектуальная работа с каталогом блоков**: выбор стандартных блоков по текстовым требованиям (попапы, обложки, колонки, формы), пополнение локальной базы шаблонов.
- **Трансляция рабочего процесса в реальном времени**: передача видеопотока из Chromium через Chrome DevTools Protocol (CDP) и WebSockets в веб-интерфейс.
- **Мультисессионный интерфейс**: сохранение истории задач, раздельные сессии и привязка параметров проектов.

## Архитектура системы

```
+-------------------------------------------------------------+
|                       Веб-интерфейс                         |
|   (Чат задач, видеотрансляция, лог действий, сессии)        |
+------------------------------+------------------------------+
                               | WebSockets / HTTP REST
+------------------------------v------------------------------+
|                    FastAPI Backend Core                     |
|                                                             |
|   +-------------------+              +------------------+   |
|   |  Agent Controller | <----------> | LLM Reasoning    |   |
|   +---------+---------+              +------------------+   |
|             |                                               |
|   +---------v---------+              +------------------+   |
|   | BrowserController | <----------> | Playwright CDP   |   |
|   +---------+---------+              +------------------+   |
+-------------|-----------------------------------------------+
              |
      +-------v-------------------------------+
      |         Chromium Instances            |
      |  [Вкладка 1] Редактор Tilda           |
      |  [Вкладка 2] Опубликованный сайт      |
      +---------------------------------------+
```

## Стек технологий

- **Backend**: Python 3.12+, FastAPI, Uvicorn, WebSockets.
- **Автоматизация браузера**: Playwright (Async API), Chrome DevTools Protocol (CDP Screencast).
- **Интеллектуальный слой**: мультимодальные модели (Gemini / HydraAI) для формирования гранулярных планов и анализа скриншотов.
- **Frontend**: React, Vite, Vanilla CSS.
- **Тестирование**: Python unittest (тесты таргетинга страниц, валидатора стилей, каталога и изоляции сессий).

## Установка и запуск

### 1. Требования
- Python 3.11 или выше
- Node.js 18+ (для сборки фронтенда при необходимости)
- Chromium (устанавливается через Playwright)

### 2. Установка зависимостей бэкенда
```bash
python -m venv venv
# Windows:
venv\Scripts\activate
# Linux/macOS:
source venv/bin/activate

pip install -r requirements.txt
playwright install chromium
```

### 3. Настройка окружения
Скопируйте шаблон `.env.example` в `.env` и укажите параметры:
```bash
cp .env.example .env
```

Заполните переменные в `.env`:
```ini
GEMINI_API_KEY=your_gemini_api_key
HYDRA_API_KEY=your_hydra_api_key

TILDA_EMAIL=your_tilda_login
TILDA_PASSWORD=your_tilda_password

HOST=127.0.0.1
PORT=8000
BROWSER_HEADLESS=false
```

### 4. Запуск сервиса
```bash
python -m uvicorn backend.main:app --host 127.0.0.1 --port 8000
```
Панель управления будет доступна по адресу: `http://127.0.0.1:8000`.
